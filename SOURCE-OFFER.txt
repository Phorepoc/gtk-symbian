GTK for Phorepoc (gtk-symbian) -- licence notice and source offer

This package contains GTK libraries built for Phorepoc OS, from unmodified upstream sources plus the changes in our repository. The libraries and their licences:
  - GTK+ 2.24.33, ATK, Pango, GdkPixbuf: LGPL-2.1-or-later (LICENSES/gtk-COPYING.txt)
  - Cairo 1.16: LGPL-2.1 or MPL-1.1 (LICENSES/cairo-COPYING.txt)
  - pixman, HarfBuzz, expat: MIT (LICENSES/pixman-COPYING.txt)
  - FreeType 2.13: FreeType License (LICENSES/freetype-LICENSE.TXT.txt)
  - fontconfig: MIT-style (LICENSES/fontconfig-COPYING.txt)
  - libpng, zlib: libpng and zlib licences (LICENSES/libpng-LICENSE.txt)
All licence texts are installed with this package in \resource\gtk-symbian\licences\ (NOTICE says which file covers what). Our own files (recipes, platform code,
overlays) are BSD-2-Clause. Each library is a separate DLL: you can replace it with your own build (modified or not) of the same library; the DLLs are linked from
archives the build leaves (see recipes/build.sh).

Corresponding source, available to anyone who has this package, for at least three years after the release you installed it from:

  1. The unmodified upstream sources, pinned (recipes/pins.sh and the dl/ folder's names):
  - GTK+ 2.24.33, ATK 2.38.0, Pango 1.40.14, GdkPixbuf 2.36.12 (https://download.gnome.org/sources/)
  - cairo 1.16.0 and pixman 0.42.2 (https://cairographics.org/releases/)
  - FreeType 2.13.3, HarfBuzz 15.1.0, fontconfig 2.14.2, expat 2.5.0, libpng 1.6.43, zlib 1.3.1
  2. Our changes to them (overlay/, patches applied by recipes/), our own files and the scripts that fetch, patch, build and package it:
       https://github.com/Phorepoc/gtk-symbian   (the release tag of this package)
     with the toolchain images and build tools in https://github.com/Phorepoc/toolchain and https://github.com/Phorepoc/pdk.

Written offer: if the links above are no longer available, send a request to the address given on the Phorepoc organisation page https://github.com/Phorepoc and we will
send you the corresponding source on a medium of your choice for the cost of the medium.
